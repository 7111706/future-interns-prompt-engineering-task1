# AI Website Copy Generator for Local Businesses

## Future Interns – Prompt Engineering Task 1 (2026)

---

## Project Overview

This project demonstrates how Prompt Engineering can generate professional, conversion-focused website copy for local businesses.

Rather than creating one piece of website content, I designed a reusable prompt framework that separates business information from copywriting instructions. By changing only the business variables, the same prompts can generate website copy for restaurants, cafés, salons, clinics, coaching centres, agencies, and freelancers.

---

## Project Objective

The objective of this project is to build a reusable AI prompt system capable of generating:

- Homepage copy
- Service page content
- Persuasive call-to-action (CTA) sections
- Business-specific messaging
- Website-ready content

## Prompt Logic

The framework is divided into four reusable sections.

### 1. Business Variables

Business-specific information is stored as variables including:

- Business Name
- Business Type
- Target Customer
- Unique Selling Proposition
- Tone
- Top Services
- Location
- Price Position
- CTA Goal

Only these variables need to change when generating website copy for another business.

---

### 2. Homepage Prompt

Generates:

- Headline
- Sub-headline
- Introduction

The prompt includes word limits and instructions to avoid generic AI language.

---

### 3. Services Prompt

Generates:

- Service name
- Description
- Why customers should choose it

The prompt requires concrete benefits instead of vague marketing phrases.

---

### 4. CTA Prompt

Creates three different website CTAs:

- Booking CTA
- Trust-building CTA
- Location/Urgency CTA

This covers multiple customer conversion points.

---

### 5. Tone Adaptation Layer

A reusable instruction adjusts the writing style for different industries.

Examples:

- Friendly (restaurants, cafés, salons)
- Professional (clinics, agencies)
- Confident-Simple (coaching businesses)
